# 智能门锁底板 EasyEDA 位号与引脚对照表

## 用法说明

这份表是给你在 `EasyEDA` 里直接照着放元件、改位号、接网络用的。

建议使用方法：

1. 先按位号放元件
2. 再按“引脚对照表”给每个引脚加网络名
3. 最后按“交叉检查表”核对一遍

---

## 一、位号总览

| 位号 | 元件名称 | 推荐器件/封装 | 作用 |
|---|---|---|---|
| `U1` | 电源模块 | 淘宝 `18650 充电/升压/UPS 5V 模块` | 整板 5V 来源 |
| `SW1` | 电源开关 | `SPST` 滑动开关 | 控制模块 5V 输出到主板 |
| `U2` | 3.3V LDO | `ME6211C33M5G-N` `SOT-23-5` | 给 Blue Pill 和 HC-04 供电 |
| `J1` | Blue Pill 左排母座 | `1x20 2.54mm Female Header` | Blue Pill 插座左侧 |
| `J2` | Blue Pill 右排母座 | `1x20 2.54mm Female Header` | Blue Pill 插座右侧 |
| `J3` | HC-04 接口 | `1x4 2.54mm Pin Header` | HC-04 模块插座 |
| `J4` | SG90 接口 | `1x3 2.54mm Pin Header` | SG90 舵机接口 |
| `J5` | 调试串口 | `1x4 2.54mm Pin Header` | 外接 USB 转串口 |
| `R1` | 舵机信号串阻 | `220R` `0603/0805` | 抑制信号尖峰 |
| `C1` | 舵机大电容 | `470uF~1000uF/10V` | 缓冲舵机启动电流 |
| `C2` | 舵机去耦 | `0.1uF` | 舵机 5V 高频去耦 |
| `C3` | LDO 输入电容 | `10uF` | 稳定 LDO 输入 |
| `C4` | LDO 输出电容 | `10uF` | 稳定 LDO 输出 |
| `C5` | LDO 输出去耦 | `0.1uF` | 3.3V 高频去耦 |
| `C6` | HC-04 本地储能 | `10uF` | HC-04 近端电源稳定 |
| `C7` | HC-04 本地去耦 | `0.1uF` | HC-04 高频去耦 |
| `MH1~MH4` | 安装孔 | `M3 NPTH` | 固定 PCB |

## 二、网络名总表

先建这些网络：

| 网络名 | 含义 |
|---|---|
| `PWR_5V_IN` | 电源模块经 `SW1` 后送到主板的 5V |
| `VCC_3V3` | 主板逻辑 3.3V |
| `GND` | 全板地 |
| `SERVO_PWM` | 舵机 PWM 信号 |
| `BLE_TX` | STM32 发给 HC-04 的串口 TX |
| `BLE_RX` | HC-04 发给 STM32 的串口 RX |
| `DBG_TX` | STM32 调试串口 TX |
| `DBG_RX` | STM32 调试串口 RX |

## 三、逐器件引脚对照表

### 1. `U1` 电源模块

因为你选的是淘宝现成模块，封装和焊盘位置以实物为准，但原理图里至少要保留这两个电气引脚：

| 元件 | 引脚/焊盘名 | 接到网络 | 说明 |
|---|---|---|---|
| `U1` | `OUT+` | `SW1-1` | 模块 5V 输出正极 |
| `U1` | `OUT-` | `GND` | 模块地 |

如果商品丝印不是 `OUT+/OUT-`，而是 `5V/GND`，那就按等价关系处理：

- `5V = OUT+`
- `GND = OUT-`

---

### 2. `SW1` 电源开关

| 元件 | 引脚 | 接到网络/器件 | 说明 |
|---|---|---|---|
| `SW1` | `1` | `U1.OUT+` | 输入端 |
| `SW1` | `2` | `PWR_5V_IN` | 输出端 |

如果你选的是三脚滑动开关：

- 一般用中间脚和一侧脚
- 另一侧脚悬空不接

---

### 3. `U2` 3.3V LDO

以 `ME6211C33M5G-N` 常见引脚定义为例，画图前再对照 EasyEDA 元件库确认一次封装引脚序号。

| 元件 | 引脚功能 | 接到网络 | 说明 |
|---|---|---|---|
| `U2` | `IN` | `PWR_5V_IN` | 输入 5V |
| `U2` | `GND` | `GND` | 地 |
| `U2` | `OUT` | `VCC_3V3` | 输出 3.3V |
| `U2` | `CE/EN` | `IN` 或上拉到 `PWR_5V_IN` | 若所选 LDO 有使能脚则保持开启 |
| `U2` | `NC` | 悬空 | 若有无功能脚则不接 |

你在 EasyEDA 中如果找的库符号不是按 `IN/GND/OUT/CE` 命名，一律以你选中的数据手册为准。

---

### 4. `C3/C4/C5` LDO 周边电容

| 元件 | 引脚1 | 引脚2 | 说明 |
|---|---|---|---|
| `C3` | `PWR_5V_IN` | `GND` | LDO 输入电容 |
| `C4` | `VCC_3V3` | `GND` | LDO 输出储能 |
| `C5` | `VCC_3V3` | `GND` | LDO 输出高频去耦 |

注意：

- 如果是极性电容，正极接电源，负极接地
- 如果是贴片陶瓷电容，不区分正负

---

### 5. `J3` HC-04 接口

这部分最重要，建议你严格按下面顺序定义：

| `J3` 引脚号 | 信号名 | 接到哪里 | 备注 |
|---|---|---|---|
| `1` | `VCC_3V3` | `VCC_3V3` | HC-04 供电 |
| `2` | `GND` | `GND` | 共地 |
| `3` | `HC04_TXD` | `BLE_RX -> PA3` | 模块 TX 到 MCU RX |
| `4` | `HC04_RXD` | `BLE_TX -> PA2` | 模块 RX 到 MCU TX |

你在原理图里可以直接写成：

- `J3-1 -> VCC_3V3`
- `J3-2 -> GND`
- `J3-3 -> BLE_RX`
- `J3-4 -> BLE_TX`

---

### 6. `C6/C7` HC-04 去耦电容

| 元件 | 引脚1 | 引脚2 | 说明 |
|---|---|---|---|
| `C6` | `VCC_3V3` | `GND` | HC-04 储能电容 |
| `C7` | `VCC_3V3` | `GND` | HC-04 高频去耦 |

---

### 7. `J4` SG90 舵机接口

建议你把 `J4` 引脚定义成下面这个顺序，后面布线最直观：

| `J4` 引脚号 | 信号名 | 接到哪里 | 备注 |
|---|---|---|---|
| `1` | `SERVO_5V` | `PWR_5V_IN` | 舵机电源 |
| `2` | `GND` | `GND` | 地 |
| `3` | `SERVO_PWM` | `R1-2` | 舵机控制信号 |

信号链完整写法：

- `PA8 -> R1-1`
- `R1-2 -> SERVO_PWM`
- `SERVO_PWM -> J4-3`

---

### 8. `C1/C2` 舵机电源滤波

| 元件 | 引脚1 | 引脚2 | 说明 |
|---|---|---|---|
| `C1` | `PWR_5V_IN` | `GND` | 舵机大电流缓冲 |
| `C2` | `PWR_5V_IN` | `GND` | 舵机高频去耦 |

如果 `C1` 是电解电容：

- 正极接 `PWR_5V_IN`
- 负极接 `GND`

---

### 9. `R1` 舵机信号串联电阻

| 元件 | 引脚1 | 引脚2 | 说明 |
|---|---|---|---|
| `R1` | `1` | `PA8` | MCU 侧 |
| `R1` | `2` | `SERVO_PWM` | 舵机侧 |

---

### 10. `J5` 调试串口

建议定义成下面顺序：

| `J5` 引脚号 | 信号名 | 接到哪里 | 备注 |
|---|---|---|---|
| `1` | `VCC_3V3` | `VCC_3V3` | 仅作电平参考，通常可不外供 |
| `2` | `GND` | `GND` | 共地 |
| `3` | `DBG_TX` | `PA9` | MCU TX |
| `4` | `DBG_RX` | `PA10` | MCU RX |

---

### 11. `J1/J2` Blue Pill 插座

这里有一个很重要的现实问题：

- `J1/J2` 的实际 **针号序号**
- 取决于你在 EasyEDA 选的母座符号方向
- 也取决于你在 PCB 中把母座旋转后的朝向

所以这部分我建议你不要靠“J1 第几脚”死记，而是靠 **Blue Pill 板上丝印功能名** 去接网络。

你只需要确保 Blue Pill 这些功能脚被接到对应网络：

| Blue Pill 功能脚 | 接到网络 | 去向 |
|---|---|---|
| `3V3` | `VCC_3V3` | 逻辑电源输入 |
| `GND` | `GND` | 共地 |
| `PA8` | `PA8` | 到 `R1` 再到舵机 |
| `PA2` | `BLE_TX` | 到 HC-04 RXD |
| `PA3` | `BLE_RX` | 到 HC-04 TXD |
| `PA9` | `DBG_TX` | 到调试口 |
| `PA10` | `DBG_RX` | 到调试口 |

强烈建议：

- 在原理图里把 `J1/J2` 每个实际用到的引脚旁边直接写上丝印功能名
- 例如写成 `PA8`、`PA2`、`PA3`
- 不要只写 `J1-7`、`J2-11` 这种没有语义的编号

## 四、最推荐的 EasyEDA 画法

为了避免 `Blue Pill` 双排座编号绕晕，我建议你在原理图中按下面方法处理：

1. `J1/J2` 继续作为实际封装位号
2. 在原理图旁边加明确网标：
   - `PA8`
   - `PA2`
   - `PA3`
   - `PA9`
   - `PA10`
   - `3V3`
   - `GND`
3. 用网络标签而不是长连线连接到 `J3/J4/J5/U2`
4. 画完后再对照 Blue Pill 实物丝印检查一遍

这样即使你后面调整了 `J1/J2` 摆放方向，也不容易接错。

## 五、最容易接错的 6 个点

### 1. HC-04 串口方向

正确：

- `HC-04 TXD -> PA3`
- `HC-04 RXD -> PA2`

不要接成同名直连。

### 2. 舵机供电

正确：

- `J4-1 -> PWR_5V_IN`

不要从 `VCC_3V3` 供电。

### 3. Blue Pill 供电

正确：

- `Blue Pill 3V3 -> VCC_3V3`

不要把 `PWR_5V_IN` 接到 Blue Pill `5V` 脚。

### 4. LDO 输入输出

正确：

- `IN -> PWR_5V_IN`
- `OUT -> VCC_3V3`

不要反过来。

### 5. 舵机电容位置

正确：

- `C1/C2` 放在 `J4` 附近

不要只放在 LDO 或 Blue Pill 附近。

### 6. 公共地

正确：

- `U1`、`U2`、`Blue Pill`、`HC-04`、`SG90`、`J5` 全部共地

不要人为把舵机地和逻辑地断开。

## 六、画完后直接照抄的核对表

### 电源

- `U1.OUT+ -> SW1-1`
- `SW1-2 -> PWR_5V_IN`
- `U1.OUT- -> GND`
- `PWR_5V_IN -> U2.IN`
- `U2.OUT -> VCC_3V3`
- `PWR_5V_IN -> J4-1`
- `VCC_3V3 -> J3-1`
- `VCC_3V3 -> J5-1`

### 串口

- `PA2 -> BLE_TX -> J3-4`
- `PA3 -> BLE_RX -> J3-3`
- `PA9 -> DBG_TX -> J5-3`
- `PA10 -> DBG_RX -> J5-4`

### PWM

- `PA8 -> R1-1`
- `R1-2 -> SERVO_PWM -> J4-3`

### 去耦

- `C1/C2 -> PWR_5V_IN 与 GND`
- `C3 -> PWR_5V_IN 与 GND`
- `C4/C5 -> VCC_3V3 与 GND`
- `C6/C7 -> VCC_3V3 与 GND`

---

## 七、还差最后一件实物确认

`U1` 的模块焊盘和安装孔现在还不能完全定死。

你拿到模块实物后，只需要补测这几项：

- 模块长宽
- 安装孔位置
- `OUT+ / OUT-` 焊盘位置
- 模块底面是否有突起器件

这些尺寸只影响 PCB 封装，不影响这份引脚对照表里的电气连接逻辑。
