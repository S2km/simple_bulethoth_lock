# STM32 智能门锁底板原理图直画说明（淘宝现成 UPS 模块版）

## 文档用途

这份文档给你一份可以直接照着在嘉立创专业版里画的原理图方案。

- 项目名：`stm32-smart-lock-baseboard`
- 板卡类型：底板
- 插接模块：
  - `STM32F103C8T6 Blue Pill`
  - `HC-04BLE`
  - `SG90 / 9g servo`
  - `淘宝现成 18650 UPS 子模块`
- 电池：`1 x 18650`

## 本版设计假设

- 使用的是 `5V 输出版本` 的现成 UPS 模块
- 充电和升压都由 UPS 模块内部完成
- 底板不再重复放 `USB-C + TP4056 + MT3608`
- 充电口优先使用 UPS 模块自带的 `Micro USB / 5V 输入`
- 底板额外保留一个 `备份 5V 输入口`，用于调试或临时外部供电
- STM32 和 HC-04BLE 使用 `3.3V`
- SG90 舵机使用 `5V`

## 关键提醒

- 下面这份原理图是按常见 `LX-LIUPS / 同类 5V UPS 子模块` 的丝印逻辑来写的
- 不同卖家的模块丝印和焊盘位置可能会改版，真正锁定 PCB 封装前，先用你手上的实物重新核对一次
- 舵机电源不要走 Blue Pill 板子的 `5V`
- 舵机和逻辑必须共地
- 如果后面你要做长期待机版智能门锁，Blue Pill 本身静态功耗偏高，这一版更适合先跑通原型

## 建议网名

先创建这些网络标签：

- `BAT+`
- `UPS_OUT_5V`
- `EXT_5V`
- `SYS_5V`
- `VCC_3V3`
- `GND`
- `PWM_PA8`
- `USART1_TX`
- `USART1_RX`
- `USART2_TX`
- `USART2_RX`

## 模块 1：UPS 子模块 `U1`

### 原理图表示方法

在原理图里把它画成一个 `6Pin 子模块符号`，名字可以写成：

- `U1 = LX-LIUPS-5V`

### 推荐引脚定义

1. `BAT+`
2. `GND`，对应电池负极
3. `UPS_OUT_5V`
4. `GND`，对应 UPS 输出负极
5. `VIN_5V_IN`，对应输入 `5V+`，本版不接
6. `GND`，对应输入 `5V-`，本版不接

### 说明

- 这版默认使用 UPS 模块自带的充电口，所以 `U1` 的 `输入5V+ / 输入5V-` 在底板原理图里先不接
- 真到 PCB 时，你可以给 `U1` 画成：
  - 自定义焊盘子模块
  - 或 6 个大焊盘加丝印说明
  - 或预留排针/飞线焊盘

## 模块 2：18650 电池座 `BT1`

### 器件

- `BT1` 单节 18650 电池座，推荐通孔件

### 连接

- `BT1 + -> BAT+`
- `BT1 - -> GND`
- `BAT+ -> U1 BAT+`
- `GND -> U1 电池负极`

## 模块 3：备份 5V 输入口 `J1`

### 器件

- `J1` 1x2 2.54mm 排针，或 `JST-XH-2A`

### 引脚

1. `EXT_5V`
2. `GND`

### 作用

- 这个口不是主供电口
- 它是给你调试用的
- 当 UPS 模块还没装好，或者你临时想直接喂 5V 看舵机和 MCU 是否正常时，可以从这里进电

## 模块 4：5V 电源 OR-ing `D1`、`D2`

### 器件

- `D1` `SS34`
- `D2` `SS34`

### 连接

- `U1 UPS_OUT_5V -> D1 阳极`
- `D1 阴极 -> SYS_5V`
- `J1 EXT_5V -> D2 阳极`
- `D2 阴极 -> SYS_5V`
- `U1 UPS 输出负极 -> GND`
- `J1 GND -> GND`

### 说明

- 这两个二极管的作用是避免 `UPS 输出` 和 `外部 5V` 互相反灌
- `SYS_5V` 就是整块底板真正使用的 5V 母线
- 用 Schottky 的原因是压降低，SG90 一般仍能正常工作

## 模块 5：5V 母线去耦和舵机接口

### 器件

- `C1` `470uF / 10V`，舵机大电流缓冲
- `C2` `22uF / 10V`
- `C3` `0.1uF / 50V`
- `J5` 1x3 2.54mm 舵机接口

### 连接

- `SYS_5V -> C1 -> GND`
- `SYS_5V -> C2 -> GND`
- `SYS_5V -> C3 -> GND`
- `J5-1 -> SYS_5V`
- `J5-2 -> GND`
- `J5-3 -> PWM_PA8`

### 说明

- `C1` 尽量靠近 `J5`
- `C2` 和 `C3` 尽量靠近 `5V` 分配点
- 舵机信号仍然来自 `PA8`

## 模块 6：3.3V 稳压 `U2`

### 器件

- `U2` `AMS1117-3.3`
- `C4` `10uF / 10V`，输入电容
- `C5` `10uF / 10V`，输出电容
- `C6` `0.1uF / 50V`，输出高频去耦

### 连接

- `SYS_5V -> U2 VIN`
- `U2 GND -> GND`
- `U2 VOUT -> VCC_3V3`
- `SYS_5V -> C4 -> GND`
- `VCC_3V3 -> C5 -> GND`
- `VCC_3V3 -> C6 -> GND`

### 说明

- 这一版先用 `AMS1117-3.3`，好画、好买、原型验证快
- 如果你后面要改低功耗版，可以把 `U2` 换成低静态电流 LDO，但原理图连接关系不变

## 模块 7：Blue Pill 插座 `J2`、`J3`

### 器件

- `J2` 左侧 1x20 母排针
- `J3` 右侧 1x20 母排针

### 必接网络

- `3V3 -> VCC_3V3`
- `GND -> GND`
- `PA8 -> PWM_PA8`
- `PA2 -> USART2_TX`
- `PA3 -> USART2_RX`
- `PA9 -> USART1_TX`
- `PA10 -> USART1_RX`

### 说明

- Blue Pill 的 `5V` 脚这版默认不接
- 你真正给 MCU 的供电是 `3.3V`
- 这样能避免把舵机电流引进 Blue Pill 板上的 5V 路径

## 模块 8：HC-04BLE 接口 `J4`

### 器件

- `J4` 1x4 2.54mm 排针
- `C7` `10uF / 10V`
- `C8` `0.1uF / 50V`

### 引脚顺序

1. `VCC_3V3`
2. `GND`
3. `TXD`
4. `RXD`

### 连接

- `J4-1 -> VCC_3V3`
- `J4-2 -> GND`
- `J4-3 -> USART2_RX -> PA3`
- `J4-4 -> USART2_TX -> PA2`
- `VCC_3V3 -> C7 -> GND`
- `VCC_3V3 -> C8 -> GND`

## 模块 9：USART1 调试口 `J6`

### 器件

- `J6` 1x4 2.54mm 排针

### 引脚顺序

1. `VCC_3V3`
2. `GND`
3. `USART1_TX`
4. `USART1_RX`

### 连接

- `J6-1 -> VCC_3V3`
- `J6-2 -> GND`
- `J6-3 -> USART1_TX -> PA9`
- `J6-4 -> USART1_RX -> PA10`

## EasyEDA 画图顺序

建议你按这个顺序画，最不容易乱：

1. 先放 `U1 UPS 子模块`
2. 再放 `BT1 电池座`
3. 放 `J1 备份 5V 输入`
4. 放 `D1 / D2`
5. 放 `C1 / C2 / C3`
6. 放 `U2 + C4 / C5 / C6`
7. 放 `J2 / J3 Blue Pill 插座`
8. 放 `J4 HC-04BLE`
9. 放 `J5 舵机接口`
10. 放 `J6 USART1 调试口`
11. 最后统一打网标

## 必查项

- `SYS_5V` 和 `VCC_3V3` 不能短在一起
- `J5-1` 必须是 `SYS_5V`，不是 `VCC_3V3`
- `HC-04BLE` 供电必须是 `VCC_3V3`
- `PA8` 只接舵机 PWM
- `PA2/PA3` 只接蓝牙串口
- `PA9/PA10` 只接调试串口
- 所有地都必须共地
- `D1` 和 `D2` 方向别画反

## PCB 阶段额外提醒

- 先别急着锁 `U1` 封装
- 最好先拿卡尺量一下你手上的 UPS 模块：
  - 模块总长总宽
  - 6 个焊盘的位置
  - Micro USB 相对板边的位置
- 如果你暂时还没量尺寸，原理图先按这里画，PCB 里先把 `U1` 当作自定义子模块占位
